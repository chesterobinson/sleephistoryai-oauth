Application information

SleepHistoryAI

A local Windows publishing tool for the owner of Whispers of the Past.

What the application does

SleepHistoryAI prepares source-based history videos locally, then uses the YouTube Data API to upload completed videos, apply titles, descriptions and thumbnails, and manage future publication times. It reads the channel owner's YouTube Analytics through a separate read-only permission.

Owner-controlled publishing

Uploads begin as private videos. Public scheduling requires a separate, channel-bound approval from the owner. The application verifies the selected YouTube Channel ID before uploading or scheduling. Existing successful local media and research archives are preserved.

Local operation and Google authorization

The publishing worker runs on the owner's Windows computer using Python, SQLite and Windows Task Scheduler. New uploads require that computer to be on and the owner to be signed in to Windows. YouTube can carry out publication times already scheduled on its servers even when the local computer is off.

Account authorization takes place on Google's own pages. This information site never asks for a Google password or an OAuth token.

Read the privacy policy to see how Google account data is accessed, used and stored. See the terms of use and YouTube Terms of Service.
