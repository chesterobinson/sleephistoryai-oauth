Privacy policy

Google data stays within the publishing workflow.

This policy describes the personal SleepHistoryAI installation operated by the owner of Whispers of the Past.

Information accessed

  • The selected YouTube channel's identifier, title, upload playlist and account capability status.
  • Video identifiers, metadata, privacy and processing status, scheduling times, and upload progress needed to manage the owner's videos.
  • Channel and video Analytics reports, including views, watch time, average viewing duration and subscriber changes, when the owner grants read-only Analytics access.
  • OAuth authorization and refresh credentials used to carry out the features the owner permits.

Purpose and sharing

Google API information is used to verify the correct channel, avoid duplicate uploads, manage private uploads and approved publication, display operational status, and review the owner's real channel statistics. It is not sold, used for advertising, or sent to a third-party AI service. Completed videos and their selected metadata are transmitted to YouTube when the owner authorizes uploading. Public availability is controlled by the owner's publication permission and YouTube settings.

Google API information is used only for these owner-facing features under the Google API Services User Data Policy, including its Limited Use requirements. Google data is not used to train general-purpose AI models.

Storage and protection

Operational records and Analytics are stored locally in SQLite on the owner's Windows computer. OAuth credentials and resumable upload URLs are encrypted using Windows DPAPI for the current Windows user. Credential values are not placed in routine logs or in this website. Local records and production archives are retained until the owner removes them; access to Google data can be revoked at any time.

Revocation and deletion

The owner can revoke the application's Google access using Google Account connections. Local Analytics can be removed using the application's channel_cli.py delete-local-analytics command. The Windows owner can remove stored authorization records from the local database/secrets directory. Copies retained from an earlier local credential migration must also be removed if present.

Removing local authorization does not automatically delete videos already uploaded to YouTube or cancel a publication time already accepted by YouTube. The owner can manage those videos and publication settings in YouTube Studio.

This information website

These static pages contain no sign-in form, advertising, application cookies, or visitor Analytics script. The hosting provider may process connection data under its own privacy statement. If hosted on GitHub Pages, GitHub records visitor IP addresses for security purposes; see GitHub's privacy statement. Google's handling of account data is described in the Google Privacy Policy.

Contact

For questions or requests, contact the operator through the Whispers of the Past channel. The application is for this owner's personal publishing workflow, not a public multi-user service.
